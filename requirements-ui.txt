# python-docx/openpyxl: used only by ui/report_export.py to let users download
# the generated MIGRATION_REPORT.md / MANUAL_TRANSLATION_REQUIRED.md as Word
# documents and feasibility_report.json as an Excel workbook, from the
# Reports tab. Both are pure-Python, dependency-light packages with no
# pandas/pyarrow version constraints, so they're safe to add here.

# Pinned to 1.58.0 specifically: it is the first Streamlit release with no
# upper bound on pyarrow (just pyarrow>=7.0) while still requiring
# pandas<4 - both compatible with this repo's requirements.txt pins
# (pyarrow==25.0.0, pandas==3.0.5). Earlier/later Streamlit releases add a
# pyarrow upper bound (e.g. 1.51.0 needs pyarrow<22, 1.60.0 needs
# pyarrow<25) that conflicts with pyarrow==25.0.0 and fails with
# ResolutionImpossible.
#
# IMPORTANT: install this in its OWN isolated virtual environment, NOT the
# same environment as requirements.txt. app.py has no direct dependency on
# pandas/pyarrow/pythonnet/deltalake - it only shells out via subprocess to
# whichever Python interpreter you configure in the UI's "Python
# executable" field (point that at your requirements.txt environment).
# Installing streamlit alongside requirements.txt in one environment risks
# pip silently resolving down to different pyarrow/pandas versions than
# the pipeline was pinned/tested against.
#
# Setup (run once, using your x64 Python):
#   <path-to-x64-python>\python.exe -m venv .venv-ui
#   .venv-ui\Scripts\python.exe -m pip install -r requirements-ui.txt
#
# Launch:
#   .venv-ui\Scripts\python.exe -m streamlit run ssas_fabric_migrator\ui\app.py
